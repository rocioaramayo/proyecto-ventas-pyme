# Análisis de ventas de una pyme

## Objetivo

Analizar ventas, rentabilidad, productos, clientes y sucursales
para encontrar oportunidades de mejora.

## Preguntas

1. ¿Cómo evolucionaron las ventas mensuales?
2. ¿Qué productos generan más facturación?
3. ¿Qué categorías tienen mayor margen?
4. ¿Qué sucursales funcionan mejor?
5. ¿Cuántos clientes vuelven a comprar?
6. ¿Qué efecto tienen los descuentos?
